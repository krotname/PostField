# 48 адресных исправлений индекса

Первый индекс Geoapify отличался от эталона ФНС у 48 из 117 адресов — 41,03%. Все 48 записей внесены в каталог; версия 0.1.3 распознаёт сокращённые и полные названия проспектов и шоссе. Сервер и повторные запросы к провайдеру не понадобились.

## Что означает процент

Расчёт использует сохранённые ответы живого измерения 13.10.2026. У 61 адреса первый индекс совпал с эталоном; у 3 ответов индекса не было, 5 запросов не завершились. Совпадение индекса само по себе не подтверждает точный дом. Из 48 расхождений 13 прежняя политика могла вставить автоматически: 13/117 = 11,11% всего корпуса, 13/20 = 65% прежних автоматических ответов.

Это описание конкретного корпуса публичных адресов организаций, а не оценка всей России. Неизвестные результаты не считаются правильными. [Исходный замер](evidence/RUSSIA_QUALITY.md) и [расчёт replay](evidence/russia-corrections-replay.json) сохраняются отдельно.

## Применение и обновление

[Машинный каталог](../src/data/russia-postcode-corrections.json) входит в каждый пакет. Для применения должны совпасть страна, город, улица, дом и регион, заданный пользователем либо возвращённый провайдером. Само исправление требует точного региона и дома кандидата. Известный неверный код кандидата другого дома удаляется из вариантов для этого запроса; в других адресах тот же шестизначный код остаётся допустимым. Новый неизвестный индекс требует ручной проверки. Автоматическое заполнение сохраняет требования единственного результата уровня building с confidence=1 и не заменяет ручное значение.

Новые подтверждённые ошибки и исправления добавляются эпизодически в очередной версии: официальный источник, точный адрес, наблюдавшийся неверный индекс, правильный индекс и дата проверки. Сохранённый пример служит регрессией; соседние дома и одноимённые города не должны попадать под исправление. Новая запись проверяется целевыми тестами, затем проходит обычный выпуск. Массовый живой повтор корпуса для обновления списка не требуется; независимая оценка стабильного выпуска остаётся отдельным условием.

Живой benchmark отклоняет пересечение со всеми 117 историческими адресами и каталогом до чтения ключа и обращения к Geoapify, учитывая поддержанные сокращения улиц. Для независимого замера задаётся `CORPUS_PATH` с отдельным корпусом ≥100 новых адресов из ≥10 регионов. [Новый корпус](../tests/fixtures/russia-independent-corpus.json) содержит 100 адресов из 41 региона; он не добавлен в исправления. Исторический корпус остаётся источником регрессий и процента ошибок. Неоднозначное сокращение «пр» в пользовательском вводе требует ручного подтверждения даже для записи каталога; улица, проспект и проезд не объединяются.

## ФИАС без собственного сервера

В опубликованных [условиях официального API ФИАС](https://fias-file.nalog.ru/docs/Условия%20использования%20API-сервисов%20ФИАС.pdf) доступ оформляется заявкой и выданным ФНС мастер-токеном; форма требует перечисления IP-адресов. Общий мастер-токен нельзя передавать третьим лицам. Собственный токен PostField не получен, пригодность прямого подключения распределённого расширения не подтверждена. Поэтому текущий источник — Geoapify BYOK с встроенным каталогом; собственный сервер не добавлен.
