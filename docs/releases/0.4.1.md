# PostField 0.4.1

Русский язык явно указан в манифестах и включён в каждый пакет. Microsoft Edge Add-ons сможет определить язык карточки из `_locales/ru/messages.json`; проверка архивов требует наличия локализованных названия и описания.

Функции 0.4.0 сохранены: локальные избранные адреса с необязательным подтверждением и предупреждение об ошибках внешних источников. Живые показатели качества остаются диагностическими и не блокируют выпуск.
