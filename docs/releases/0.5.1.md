# PostField 0.5.1

Если все найденные записи дают один индекс и есть надёжная точная запись дома, индекс подставляется сам, без кнопок вариантов. Кнопки выбора группируются по индексу: один индекс — одна кнопка.

Район рядом с улицей («жилой район …», «мкр …») не мешает точному совпадению дома, но остаётся в ключе адреса: смена района во время запроса по-прежнему считается новым адресом.

Статус читается на тёмных сайтах: собственные цвета текста и фона, текст отдельной строкой. Пустая плашка статуса скрыта до ответа источника и после смены адреса.

GitHub Release опубликован. Поведение проверено целевыми тестами и живым смоком на публичных страницах; точность поставщика не заявляется.
