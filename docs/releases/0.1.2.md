# PostField 0.1.2 — 48 адресных исправлений без сервера

В расширение встроен список известных неверных индексов Geoapify и правильных значений из официальных реквизитов ФНС. При точном совпадении региона, города, улицы и дома индекс исправляется; известный неверный вариант другого дома отфильтровывается. Остальные ответы требуют ручного выбора. Ручное значение сохраняется.

У 48 из 117 адресов первый индекс Geoapify расходился с эталоном — 41,03%. Из них 13 прежняя версия могла вставить автоматически (11,11% всего корпуса). Расчёт и проверка исправлений использовали сохранённые ответы, без новых запросов к провайдеру.

Каталог обновляется вместе с версиями расширения. Сервер не нужен, провайдер остаётся Geoapify BYOK. Повторная проверка тех же примеров не доказывает качество на новых адресах; стабильный выпуск и доставка в магазины остаются закрыты. ZIP — предварительные пакеты для самостоятельной загрузки, а не подписанные магазинные дистрибутивы. Выпуски 0.1.0 и 0.1.1 неизменны.
