# PostField 0.1.4 — независимый корпус и защита измерения

Benchmark отклоняет любой из 117 прежних адресов до чтения ключа и HTTP, включая адреса вне каталога исправлений. Распознавание сокращений и каталог из 48 записей сохраняются.

Подготовлен отдельный корпус из 100 новых официальных адресов ФНС, 41 регион, максимум 9%. Корпус не используется для новых исправлений. Рабочая политика на подставных идеальных ответах оставляет все 100 новых индексов на ручном выборе: при неизменной реализации порог ≥90% автоматического заполнения недостижим. Это проверка политики, а не новый замер точности Geoapify; внешних запросов к провайдеру 0. Историческая доля расхождений 48/117 = 41,03% относится к прежней выборке.

Обновлён подтверждённый статус настройки API магазинов. Новый Edge draft существует; Chrome OAuth и AMO JWT настроены. Регистрация Chrome, выбор публичного имени AMO, свежая HTTP-аутентификация Opera и независимый stable quality gate остаются условиями доставки. ZIP, upload, submission и публикация различаются.

Изменения относятся к исходникам версии 0.1.4. Предварительные релизы v0.1.0–v0.1.3 неизменны; новый GitHub Release и пакеты в магазины этим изменением не отправляются.
