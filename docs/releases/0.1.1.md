# PostField 0.1.1 — проверка индекса перед заполнением

Точное совпадение дома в Geoapify не гарантирует правильный индекс. Для России расширение теперь показывает предупреждение и заполняет индекс только после явного выбора пользователя. Ручное значение и защита от устаревших ответов сохраняются.

Подготовлен независимый корпус: 117 разных официальных публичных адресов из 26 регионов. Порог стабильного выпуска остаётся прежним: ноль неверных автоматических вставок, ноль ошибок и ≥90% правильных подтверждений. Он пока не выполнен; доставка в магазины закрыта.

Предварительные ZIP не являются подписанными дистрибутивами магазинов. Выпуск 0.1.0 неизменяем и не содержит новой защиты. Международные страны остаются отключёнными.
