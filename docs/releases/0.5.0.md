# PostField 0.5.0

Единый пакет для Firefox на компьютере и Android сохраняет GUID postfield@krot.name и настройки пользователей. Минимальная версия Firefox Android — 142.

Всплывающее окно и ручное сопоставление полей адаптированы к узким экранам, сенсорному управлению и экранной клавиатуре. Сохранены ручной индекс, разделение форм и хранение ключей провайдеров вне страницы.

GitHub Release опубликован. Версия Mozilla 6610083, файл 5154202 поданы с исходниками и ожидают модерации; подписанная установка пока не подтверждена.
