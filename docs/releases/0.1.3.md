# PostField 0.1.3 — исправления для проспектов и шоссе

Каталог из 48 адресов теперь распознаёт сокращённые и полные названия типов улиц: «пр-кт» и «проспект», «ш» и «шоссе», в начале либо конце названия. Улица и проспект остаются разными адресами; неоднозначное «пр» требует ручного выбора. Известный неверный индекс исправляется либо удаляется из вариантов, ручное значение сохраняется.

Адреса из каталога не допускаются в независимый живой benchmark: совпадение обнаруживается до первого запроса к провайдеру, включая сокращения. Для проверки стабильного выпуска нужен отдельный корпус новых адресов. Историческая доля расхождений — 48/117 = 41,03%; подсчёт и регрессии выполнены без новых запросов к Geoapify.

Это предварительный выпуск без собственного сервера. Неизвестные индексы требуют проверки; стабильная публикация в четырёх магазинах ещё не подтверждена. Выпуски 0.1.0–0.1.2 неизменны.
