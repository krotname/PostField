# PostField 0.2.0

- После настройки личного ключа Geoapify и согласия включён режим «Авто» на HTTP(S)-сайтах. Переключатель «Авто / Вручную» запоминает выбор текущего сайта.
- Поля распознаются по autocomplete, HTML-меткам, ARIA, соседним подписям и ячейкам таблицы. Поддержаны русский, английский, немецкий, французский, испанский, итальянский, португальский, польский, турецкий, китайский, японский и арабский; география поиска остаётся российской.
- Повторяющиеся адресные блоки, доставка и оплата обрабатываются отдельно; скрытые поля исключаются, динамические диалоги пересканируются.
- Единственное точное совпадение города, улицы и дома с confidence=1 и result_type=building разрешает вставку. Сохранены 48 адресных исправлений и защита неоднозначных результатов, ручного индекса и устаревших ответов.
- Ошибки сети, таймаута, ключа, квоты, HTTP, хранилища и обмена со службой расширения различаются. Статус расположен рядом с адресным блоком, повтор запускается кнопкой; ошибка не попадает в поле индекса.

API-ключ и согласие сохраняются при обновлении. Ручной режим переживает перезапуск браузера. Точность геокодирования не гарантирует правильность индекса Geoapify; независимый quality gate стабильного выпуска остаётся обязательным. Магазинная публикация этим изменением не выполняется.
