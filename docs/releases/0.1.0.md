PostField 0.1.0 — предварительный выпуск расширения для поиска почтового индекса по адресу в форме. Первый этап — Россия; требуется собственный ключ Geoapify и согласие на запросы.

Доступны разовое заполнение, автоматический режим для выбранного сайта, ручное назначение полей, выбор неоднозначного результата и сохранение ручного индекса. Расширение не отправляет формы и не передаёт ФИО или квартиру.

Assets: ZIP для Chrome, Opera, Edge и Firefox; архив исходников для модераторов; release-manifest с SHA и версиями. Firefox ZIP предназначен для временной загрузки разработчиком и проверки: подписанный XPI для постоянной установки появится после AMO. Пакеты собраны GitHub Actions и имеют аттестацию происхождения.

Код и тесты доступны публично под Source-Available and Official Binary License. Издатель — Kreout. Публикация в магазинах и качество Geoapify на полном корпусе РФ ещё не подтверждены. Международные страны пока не включены.
