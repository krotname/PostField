# От адреса в форме до четырёх магазинов

PostField определяет индекс нового адреса без сохранённого профиля. РФ — первый этап; США, Канада, Великобритания и Германия включаются после отдельных проверок качества.

## Этапы и критерии

1. Проверить возможности Geoapify на контрольных публичных адресах РФ, доступы магазинов и HTTP-публикацию Opera. У Opera нет найденного документированного Publish API; внутренний контракт требует живой проверки. При неподтверждённом контракте выпуск в этот магазин остаётся заблокированным.
2. Создать публичный репозиторий, лицензию с сохранением прав, узкие порты SOLID, строгую типизацию, TDD и CI без секретов для PR.
3. Реализовать адресные группы, личный ключ, согласие, одноразовое заполнение, режим по сайту, неоднозначные результаты, сохранение ручного значения и защиту от устаревших ответов.
4. Собрать четыре ZIP и архив исходников для модераторов. Подготовить privacy/support/demo, карточки и адаптеры Chrome v2, Edge v1.1, AMO v5 и Opera HTTP.
5. GitHub Release запускает независимую доставку. ID операций сохраняются; повтор продолжает ту же подачу. Публикация подтверждается версией в магазине и обычной установкой после перезапуска браузера.
6. Для международных стран проверить формат, сопоставление адресов и контрольный корпус; затем включить страны тем же pipeline.

## Опыт Password Field Inspector / PassField

- Отдельные пакеты Chromium и Firefox, allowlist содержимого, синхронная версия и исходники для модератора.
- Сохранение ID карточек и подач, различение загрузки, модерации и публичного выпуска.
- Обычная подписанная установка Firefox и проверка после перезапуска.
- Для PostField — новые ID и ключи. Политика приватности изменена: адрес передаётся Geoapify, а не остаётся полностью локальным.
- Историческая модерация Opera длилась несколько недель; это наблюдение, а не обещание срока.

## Качество

Ноль неверных автоматических вставок в контрольном корпусе. Недостаточное покрытие снижает число заполнений, но не порог доверия. Совпадение города или улицы не разрешает автоматическую подстановку индекса дома.
