# Архитектура PostField

Чистое ядро решает, можно ли доверять индексу. DOM, Geoapify, хранение и доставка заменяются через узкие порты; ядро не знает браузера и сети.

| Слой | Ответственность | Зависимости |
|---|---|---|
| core | Адрес, формат индекса, точное совпадение | Только core |
| application | Поиск, кэш, владение заполненным значением | core, порты |
| adapters | Geoapify, поля формы, IndexedDB, настройки | Порты application |
| browser | Popup/options, сообщения, жизнь страницы | Композиция адаптеров |
| delivery | Журнал и API магазинов | StorePort, Journal |

## SOLID

SRP: политика адресов, состояние формы, распознавание DOM и сетевой адаптер имеют отдельные причины изменения. OCP: новый провайдер реализует AddressProvider, новый магазин — StorePort. LSP: контракт LookupResult и StorePort один для всех адаптеров; неподдерживаемая возможность объявляется через ready(). ISP: CredentialStore, SettingsStore и Journal разделены. DIP: LookupPostcode и FormSession получают зависимости, не создают браузер/HTTP/хранилище. Композиция находится в background.ts и scripts/deliver.ts. `npm run check:boundaries` проверяет направления зависимостей и запрет explicit any.

## Защита данных и значений

Content script получает результат поиска, но не ключ. Только собственные popup/options могут изменять ключ и настройки. Ключ находится в IndexedDB origin расширения; синхронизация браузера его не получает. Настройки сохраняют согласие и разрешённые origins. Адреса и ответы находятся только в ограниченном кэше процесса; истории адресов нет.

Автоматический поиск требует отдельного разрешения сайта и согласия. Разовый вызов действует в выбранной вкладке 60 секунд; назначение полей — 5 минут. Запрос содержит страну, город, улицу, дом и необязательный регион. Квартира, ФИО и URL страницы не отправляются. Подтверждение требует единственного точного результата уровня building с confidence=1 и отсутствия требования проверки индекса. Geoapify для РФ ставит `requiresPostcodeConfirmation=true`: уверенность геокодирования не доказывает правильность индекса дома. Поэтому пользователь видит предупреждение и явно выбирает результат. Ручной индекс не заменяется; устаревший ответ после изменения адреса отбрасывается.

Закрытый shadow DOM и фреймы другого origin без отдельного разрешения недоступны. Если группы полей неоднозначны, используется ручное назначение. Оно действует только на текущей странице и не сохраняет селекторы. Автоматическая отправка формы отсутствует.

## Подпись

Едины издатель Kreout, версия, исходный SHA и процесс выпуска. Магазины подписывают свои пакеты; одинаковый закрытый CRX-ключ нельзя использовать как универсальную подпись Firefox и магазинов. Firefox GUID: `postfield@krot.name`. Остальные IDs создаются отдельно. GitHub выпускает ZIP и архив исходников для модератора с аттестацией происхождения. Firefox ZIP из GitHub не является подписанным устанавливаемым XPI.

## Ограничения тестов

Unit/contract tests проверяют реальные решения и ошибки, а не только вызовы. E2E загружает собранное расширение в изолированный Chromium: тестовый localhost заранее разрешён, HTTP Geoapify заменён фикстурой до запуска worker. Остальные слои и сообщения настоящие. Это не доказывает качество Geoapify, диалог выдачи разрешений, работу всех сайтов или постоянную установку Firefox; такие проверки входят в ворота стабильного выпуска.
