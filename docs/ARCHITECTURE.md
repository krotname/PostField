# Архитектура PostField

Чистое ядро решает, допускается ли вставка индекса. DOM, Photon, Geoapify, DaData, хранение и доставка заменяются через узкие порты; ядро не знает браузера и сети.

| Слой | Ответственность | Зависимости |
|---|---|---|
| core | Адрес, формат индекса, точное совпадение | Только core |
| application | Поиск, кэш, владение заполненным значением | core, порты |
| adapters | Photon, Geoapify, DaData, поля формы, IndexedDB, настройки | Порты application |
| browser | Popup/options, сообщения, жизнь страницы | Композиция адаптеров |
| delivery | Журнал и API магазинов | StorePort, Journal |

## SOLID

SRP: политика адресов, состояние формы, распознавание DOM и сетевой адаптер имеют отдельные причины изменения. OCP: новый провайдер реализует AddressProvider, новый магазин — StorePort. LSP: контракт LookupResult и StorePort один для всех адаптеров; неподдерживаемая возможность объявляется через ready(). ISP: CredentialStore, SettingsStore и Journal разделены. DIP: LookupPostcode и FormSession получают зависимости, не создают браузер/HTTP/хранилище. Композиция находится в background.ts и scripts/deliver.ts. `npm run check:boundaries` проверяет направления зависимостей и запрет explicit any.

## Защита данных и значений

Content script получает результат поиска, но не ключ. Только собственные popup/options могут изменять ключ и настройки. Ключ находится в IndexedDB origin расширения; синхронизация браузера его не получает. Настройки сохраняют согласие и разрешённые origins. Адреса и ответы находятся только в ограниченном кэше процесса; истории адресов нет.

Новая установка использует Photon, включённую передачу и «Авто». Миграция сохраняет Geoapify, ключ, прежнее разрешение передачи и ручные исключения. Автоматический поиск требует разрешённой передачи, готового выбранного источника, HTTP(S)-доступа, глобального «Авто» и отсутствия ручного исключения. Разовый вызов действует в выбранной вкладке 60 секунд; назначение полей — 5 минут.

ProviderLookup маршрутизирует только выбранный AddressProvider и разделяет кэш. MessageService отменяет запросы и очищает кэш при изменении источника, режима или ключей; поколение запросов не допускает возврата устаревшего результата. Photon выполняет очередь с интервалом не менее секунды и учитывает Retry-After; язык default.

Запрос содержит страну, город, улицу, дом и необязательный регион. Квартира, ФИО и URL страницы не добавляются. Автовставка требует единственного точного полного адреса без конфликта индексов. Photon подтверждает явные компоненты без выдуманного confidence; DaData проверяет qc=0, qc_house=2, qc_complete=0/5, актуальность=0, идентификатор дома и отсутствие неразобранных частей. Geoapify сохраняет confidence=1, building, проверки противоречивых ответов и [каталог исправлений](POSTCODE_CORRECTIONS.md). Частичные и неоднозначные ответы требуют выбора. Ручной индекс не заменяется; устаревший ответ после изменения адреса отбрасывается. Правило вставки не является независимым доказательством правильности индекса поставщика.

Закрытый shadow DOM и фреймы другого origin без отдельного разрешения недоступны. Если группы полей неоднозначны, используется ручное назначение. Оно действует только на текущей странице и не сохраняет селекторы. Автоматическая отправка формы отсутствует.

## Подпись

Едины издатель Kreout, версия, исходный SHA и процесс выпуска. Магазины подписывают свои пакеты; одинаковый закрытый CRX-ключ нельзя использовать как универсальную подпись Firefox и магазинов. Firefox GUID: `postfield@krot.name`. Остальные IDs создаются отдельно. GitHub выпускает ZIP и архив исходников для модератора с аттестацией происхождения. Firefox ZIP из GitHub не является подписанным устанавливаемым XPI.

## Ограничения тестов

Unit/contract tests проверяют решения, ошибки, миграцию и отмену запросов. E2E загружает собранное расширение в изолированный Chromium: HTTP выбранного провайдера заменён фикстурой до запуска worker. Остальные слои и сообщения настоящие. Это не доказывает качество данных провайдеров, работу всех сайтов или постоянную установку Firefox; такие проверки входят в ворота стабильного выпуска.
