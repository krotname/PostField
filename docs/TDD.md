Кандидаты другого города, улицы, дома или региона не получают автоматического подтверждения. Новый неизвестный код остаётся на проверке. Индексы каталога сверены с официальными источниками; сохранённые ответы содержат только используемые публичные поля. Все регрессии работают без внешнего HTTP. Replay тех же данных — проверка исправления, а не новый независимый замер качества.

14.10.2026 05:12:55 МСК: три теста расширенных названий проспектов/шоссе получили ambiguous вместо исправленного confirmed; два теста исключения известных адресов не получили ожидаемого отказа. Это подтверждённый RED до изменения поведения. 05:13:49: все 76 тестов адаптера и корпуса прошли. Улица и проезд не превращаются в проспект; неоднозначное «пр» остаётся на ручной проверке. После этих регрессий полный GREEN — 207 тестов, TypeScript strict и SOLID, покрытие по строкам 96,34%.

Нормализация используется для сопоставления каталога и исключения обучающих адресов. Live benchmark передаёт весь каталог в проверку корпуса до чтения ключа и первого HTTP-запроса. Исторический агрегат не переписывается успешным replay.

## Исключение исторических адресов 0.1.4

15.10.2026: два новых теста `historical baseline address` и `historical baseline aliases` упали до изменения реализации: проверка принимала старый адрес вне каталога и его запись с «г.»/«улица». После добавления полного исторического набора в `inspectCorpus` все 7 тестов корпуса прошли. Фактический entry point benchmark также остановился с `historical_corpus_overlap`: чтений ключа 0, HTTP-запросов 0. Проверка каталога сохраняет прежний приоритет `catalogue_corpus_overlap`.

Дополнительно проверены новый независимый корпус и его граница доверия: 100 разных официальных адресов, 41 регион, максимум 9%; пересечений с историческим набором и каталогом нет. Два теста `unseen Russia addresses` прошли вместе с 7 тестами корпуса. Для каждого нового адреса рабочие GeoapifyProvider и LookupPostcode получили через подставной транспорт точный адрес и правильный индекс, confidence=1, result_type=building: все 100 результатов остались на ручном выборе. Это воспроизводимое доказательство ограничения текущей политики, не живая оценка провайдера и не прохождение stable gate. Команда: `npx --no-install vitest run tests/delivery/corpus.test.ts tests/adapters/russia-independent-policy.test.ts`.
