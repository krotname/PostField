Каждый цикл фиксирует наблюдаемое поведение, реальный red и целевой green. Это журнал разработки, а не замена тестов.

Новые страны имеют только правила формата; автоопределение для них отключено до независимого контрольного корпуса.

В E2E первый запуск выявил недостающую версию тестового Chromium, затем ненадёжный перехват fetch service worker. HTTP-порт заменён до запуска worker в изолированной тестовой копии; pregrant localhost описан в ARCHITECTURE.md. Сам продукт и канонические ZIP этим не изменяются. Исходники и lockfile доступны в source archive для повторной сборки. Живая проверка провайдера: [RUSSIA_QUALITY.md](evidence/RUSSIA_QUALITY.md); публикация и установка из магазинов ещё не подтверждены.
