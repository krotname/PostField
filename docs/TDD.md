# Доказательства TDD

Каждый цикл фиксирует наблюдаемое поведение, реальный red и целевой green. Это журнал разработки, а не замена тестов.

| Цикл | Red | Green |
|---|---|---|
| Правила совпадения адреса | `npm test`: отсутствует address-policy, 1 failed suite | 25 tests passed: дом, неоднозначность, форматы, ведущие нули |
| Провайдер и повторный запрос | `npm test`: отсутствует geoapify; две параллельные заявки вызывают провайдер дважды | Заполняется после целевой проверки |

Новые страны имеют только правила формата; автоопределение для них отключено до независимого контрольного корпуса.
