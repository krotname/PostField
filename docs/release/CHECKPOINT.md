# PostField 0.1.0 — состояние выпуска

Репозиторий: https://github.com/krotname/PostField. Издатель: Kreout. Предварительные пакеты предназначены для самостоятельной загрузки расширения; публикация в магазинах не подтверждена.

## Что реализовано

Россия включена первой. Geoapify BYOK, согласие и разрешения на конкретные сайты, точное совпадение дома, ручной выбор, сохранение ручного индекса, динамические формы, группы shipping/billing и ручное назначение полей. Страны US/CA/GB/DE имеют правила формата и отключены до проверки качества.

GitHub-hosted сборки, проверка пакетов, immutable release и attestations, отдельные API-адаптеры Chrome/Edge/AMO, журнал состояний в GitHub issues и продолжение незавершённых операций по расписанию. Opera adapter сообщает requires_setup до подтверждения HTTP-контракта.

## Точные оставшиеся условия

- `docs/evidence/russia-quality.json`: not_run. Нет тестового ключа Geoapify; в доступном User-окружении и узком поиске Vaultwarden запись не найдена. Подготовлены три публичных адреса; для стабильного выпуска нужен независимый корпус ≥100 и установленный порог качества.
- Для PostField отсутствуют новые CWS item, Edge product, AMO listed addon и Opera package, а также API credentials в GitHub environments. Идентификаторы PassField не используются.
- Не подтверждён HTTP-контракт Opera. Браузерное резервирование своего окна на White не завершилось: атомарная запись `agent-tabs.json` получила EPERM; текущий token не имеет права записи в существующий файл. ACL не менялись, чужие вкладки не использовались.
- Альтернативный административный маршрут WinRM проверен: локальный DPAPI credential importer не нашёл конфиг, а разрешённый реквизит KRT из Vaultwarden получил AccessDenied. Браузерные действия не выполнялись через непроверенный target.
- Подписи магазинов, постоянная установка Firefox XPI и обновление всех четырёх браузеров ещё требуют фактической публикации и install/readback.

Новых универсальных правил релиза нет. Изменения статусов и журнал каждой попытки API-доставки сохраняются в связанных GitHub issues.
