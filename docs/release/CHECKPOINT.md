# PostField 0.3.0 — состояние исходников и доставки

Подготовлен независимый корпус из 100 новых официальных адресов ФНС, 40 регионов, максимум 9%. Stable quality gate пока не пройден; историческая offline-проверка относится к политике до 0.2.0, когда все адреса вне каталога требовали выбора. [Доказательства и пределы](../evidence/RUSSIA_QUALITY.md).

Репозиторий: https://github.com/krotname/PostField. Целевой издатель: Kreout. Последний GitHub prerelease — [v0.1.3](https://github.com/krotname/PostField/releases/tag/v0.1.3); v0.1.0–v0.1.3 неизменны. Новая версия исходников 0.3.0 не означает загрузку в магазины или подписанный дистрибутив.

## Изменение исходников 0.3.0 — 22.10.2026

Photon без ключа по умолчанию для новой установки, Geoapify BYOK и DaData Clean с отдельными токеном и секретом. Глобальный и локальный режимы, очередь Photon, проверки качества по источнику, отмена запросов и раздельный кэш. Миграция сохраняет Geoapify, ключ, разрешение передачи и ручные исключения. [Изменения](../releases/0.3.0.md). Независимая живая оценка качества трёх источников и публикация в магазинах в это обновление не входят.

Серверные `npm run check` и E2E: 298 тестов, четыре пакета, проверка пяти архивов и 6 сценариев Chromium — успешно. Проверены новая установка, миграция и перезапуск; снимки интерфейса при увеличенном масштабе просмотрены. [Доказательства RED/GREEN](../TDD.md).

## Изменение исходников 0.2.0 — 21.10.2026

Режим «Авто» по умолчанию после ключа и согласия; переключатель «Авто / Вручную» для текущего сайта. Подписи на 12 языках, соседние ячейки таблиц и отдельные повторяющиеся адресные блоки; статус вне поля и повтор запроса. Единственный точный ответ Geoapify допускает вставку по выбранному правилу, известные адресные исправления сохранены. Это изменение политики, а не подтверждение точности индекса. Серверные проверки: 265 тестов, четыре пакета, проверка архивов и 3 Chromium smoke прошли. Живые формы Geni и AliExpress распознаны и заполнены выбором предложенного варианта; исправлен вызов браузерного fetch, ранее завершавшийся Illegal invocation до HTTP-запроса. Публикация в магазинах и stable gate этой работой не выполняются.

## Исторически реализовано до 0.2.0

Geoapify BYOK, согласие и разрешения на конкретные сайты, ручной выбор, сохранение ручного индекса, динамические формы, разделение shipping/billing и ручное назначение полей. Каталог 48 исправлений проверяет регион, город, тип/название улицы и дом; известный неверный вариант другого дома фильтруется. Неизвестные российские индексы требуют выбора. Собственного сервера нет. US/CA/GB/DE выключены до своих проверок качества.

Benchmark перед чтением ключа/HTTP исключает все 117 исторических адресов, их страницы источников и каталог с поддержанными вариантами записи. Новый корпус не добавлен в исправления. Исторический baseline и offline replay не изменены. Доля расхождений первого индекса 48/117 = 41,03%, прежних неверных автоматических вставок 13/117 = 11,11% — показатели конкретного прежнего набора, не оценка всей России. [Каталог](../POSTCODE_CORRECTIONS.md), [TDD](../TDD.md).

GitHub-hosted CI, четыре ZIP и архив исходников, immutable release/attestations, API-адаптеры Chrome/Edge/AMO, журнал операций в GitHub issues и продолжение доставки по расписанию. Uploaded, submitted и published различаются; неизвестный исход POST требует readback до повтора.

## Оставшиеся условия

1. Надёжное подтверждение индекса дома вне каталога, новое поведение и живой независимый quality gate того же SHA: ≥100 адресов, ≥10 регионов, максимум 20%, wrongAutomatic=0, errors=0, confirmedRate≥0.9. [Историческая offline-проверка прежней политики](../evidence/russia-independent-policy.json) дала 0 автоматических и 100 ручных вариантов с идеальными подставными ответами; она не измеряет точность провайдера.
2. Chrome: OAuth настроен, refresh HTTP200; неоплаченная регистрация требует $5, publisher/item IDs отсутствуют. Платёж не разрешён и не выполнялся.
3. Edge: новый product a8f939c3-649a-476d-a638-660e09c8b742, InDraft; publisher Kreout, store ID0RDCKDVTJVP6. API1.1 credentials настроены, карточка properties сохранена. Первая публикация Partner Center не выполнена; Update API с пакетом не проверен. Повторный draft не нужен.
4. AMO: JWT60s HTTP200, GUID postfield@krot.name отсутствует (404). Нужны решение о публичном имени общего профиля krotname, listed карточка и custom license. Старое дополнение не менялось.
5. Opera: официальные маршруты/versioned JSON известны, свежая HTTP-аутентификация не подтверждена. Новый package ID отсутствует, доставка requires_setup. Автоматические CAPTCHA-попытки исчерпаны; повтор без нового разрешённого способа входа не выполняется.
6. После одобрения магазинов — подписи, обычная установка и обновление четырёх браузеров, постоянная установка Firefox XPI и readback. GitHub ZIP этого не доказывает.

Настройка магазинов подтверждена 14.10.2026; [журнал #5](https://github.com/krotname/PostField/issues/5) содержит точный статус и связан с этим checkpoint. Environments chrome/edge/firefox/opera созданы с main/v*, соответствующие secrets сохранены без публикации значений. Preview в магазины не загружался.
