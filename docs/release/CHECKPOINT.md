# PostField 0.1.1 — состояние выпуска

Репозиторий: https://github.com/krotname/PostField. Издатель: Kreout. Предварительные пакеты предназначены для самостоятельной загрузки расширения; публикация в магазинах не подтверждена.

## Что реализовано

Россия включена первой. Geoapify BYOK, согласие и разрешения на конкретные сайты, ручной выбор, сохранение ручного индекса, динамические формы, группы shipping/billing и ручное назначение полей. Версия 0.1.2 включает 48 адресных исправлений без сервера: точный дом получает проверенный индекс, известный неверный вариант другого дома удаляется; неизвестные ответы требуют выбора. Предварительные 0.1.0 и 0.1.1 неизменны. Страны US/CA/GB/DE имеют правила формата и отключены до проверки качества.

GitHub-hosted сборки, проверка пакетов, immutable release и attestations, отдельные API-адаптеры Chrome/Edge/AMO, журнал состояний в GitHub issues и продолжение незавершённых операций по расписанию. Временная недоступность credentials сохраняет ID начатой доставки. Opera adapter сообщает requires_setup до проверки аутентификации и реализации загрузки.

## Точные оставшиеся условия

- `docs/evidence/russia-quality.json`: insufficient. Бесплатный ключ получен; независимый корпус содержит 117 разных публичных адресов из 26 регионов, максимальная доля региона 6,84%. Живой baseline 0.1.0 дал 13 неверных автоматических вставок, 7 правильных, 97 неподтверждённых результатов, включая 5 ошибок связи. Для стабильного выпуска нужен надёжный источник индекса дома и повторная оценка актуальной реализации: ноль неверных автоматических вставок, ноль ошибок и ≥90% правильных подтверждений. [Источники и измерение](../evidence/RUSSIA_QUALITY.md).
- Для PostField отсутствуют новые CWS item, Edge product, AMO listed addon и Opera package, а также API credentials в GitHub environments. Идентификаторы PassField не используются.
- Opera: подтверждены versioned JSON API, OPTIONS схемы и маршруты загрузки/модерации официального клиента. Свежая HTTP-аутентификация для CI пока не подтверждена; доставка отключена. Первоначальная карточка должна иметь новый package ID.
- Подписи магазинов, постоянная установка Firefox XPI и обновление всех четырёх браузеров ещё требуют фактической публикации и install/readback.

Доля расхождений первого индекса — 48/117 = 41,03%; доля прежних неверных автоматических вставок — 13/117 = 11,11%. Расчёт и регрессии используют сохранённые ответы без повторного запроса провайдеру. 199 тестов, TypeScript strict и границы SOLID прошли; покрытие core/application/adapters по строкам 96,18%, core 100%. [Каталог и порядок обновления](../POSTCODE_CORRECTIONS.md). Повтор тех же примеров не заменяет независимую оценку. Изменения статусов и журнал каждой попытки API-доставки сохраняются в связанных GitHub issues. Профиль выпуска: [PRODUCT_PROFILE.md](../../PRODUCT_PROFILE.md).
