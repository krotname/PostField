PostField

Индекс по адресу в форме

Укажите город, улицу и дом на сайте — PostField найдёт почтовый индекс. Первый выпуск поддерживает Россию.

Получить ключ Geoapify. Ключ хранится локально в расширении. Издатель его не получает.

Вы управляете заполнением

Откройте значок PostField на нужном сайте. После настройки действует режим «Авто» на HTTP(S)-сайтах. Для каждого сайта можно выбрать «Вручную»: поля распознаются, поиск запускается кнопкой. Единственный точный результат по городу, улице и дому заполняется сразу; неоднозначные результаты предлагаются для выбора. Точность индекса Geoapify не гарантируется. Введённый вручную индекс сохраняется.

Для нестандартной формы доступно ручное назначение полей. Формы не отправляются автоматически.

Сайты в ручном режиме

    Режим сайта меняется во всплывающем окне PostField. Отзыв согласия останавливает запросы на всех сайтах.
