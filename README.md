# PostField

Почтовый индекс по адресу, который уже введён в форму. Первый выпуск — для России; международные страны подключаются после проверки качества.

Издатель: **Kreout**. Публичные исходники и бесплатные официальные сборки для Chrome, Opera, Microsoft Edge и Firefox. Правообладатель сохраняет права на исходный код: см. [LICENSE](LICENSE).

## Принятые решения

- Geoapify с личным API-ключом пользователя (BYOK), без собственного сервера.
- Поиск только после согласия; автоматическое заполнение включается отдельно для каждого сайта.
- Автоматическая вставка только при однозначном совпадении дома. Ручной индекс сохраняется.
- Адреса не сохраняются в истории и не отправляются издателю. Получатель запросов — Geoapify.
- Строгий TypeScript, SOLID и TDD: сначала падающий тест поведения, затем реализация и рефакторинг.
- GitHub Actions собирает четыре пакета; доставка стабильного GitHub Release в магазины предусмотрена через HTTP API и журнал операций. Chrome, Edge и Mozilla имеют контрактные адаптеры; для Opera контракт ещё требуется подтвердить.
- Общий издатель и происхождение сборок; магазины используют собственные подписи и разные ID расширения.

## Установка предварительного выпуска

1. Скачайте ZIP своего браузера из [GitHub Releases](https://github.com/krotname/PostField/releases) и распакуйте его.
2. В Chrome, Edge или Opera откройте страницу расширений, включите режим разработчика и выберите «Загрузить распакованное расширение».
3. В Firefox откройте `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → `manifest.json`. Такая установка действует до перезапуска Firefox; постоянный подписанный XPI появится после проверки AMO.
4. В настройках PostField сохраните личный [Geoapify API key](https://www.geoapify.com/get-started-with-maps-api/) и согласие на отправку адреса в Geoapify.
5. Заполните город, улицу и дом; откройте PostField и нажмите «Заполнить индекс». Автоматическое заполнение включается отдельно для текущего сайта. Если поля не распознаны, используйте ручное назначение.

Версия 0.1.0 — предварительная: качество на независимом корпусе РФ ещё не измерено. При неоднозначном ответе выберите вариант сами; ручной индекс расширение сохраняет. Публикация в магазинах пока не подтверждена. Состояние и условия стабильного выпуска: [checkpoint](docs/release/CHECKPOINT.md).

## Разработка

Требуется Node.js 24+. `npm ci`, затем `npm run check`. Для проверки браузера: `npx --no-install playwright install chromium`, `npm run test:e2e`. CI дополнительно проверяет покрытие, зависимости и Firefox manifest. Выпуск создаёт четыре ZIP, source archive, release manifest и GitHub build attestations из проверенного SHA main.

`npm run benchmark:ru` читает `GEOAPIFY_API_KEY` из окружения; корпус задаётся `CORPUS_PATH`, путь агрегированного отчёта — `REPORT_PATH`. Ключ, ответы с адресами и пользовательские данные в отчёт не попадают. Стартовые три адреса не открывают стабильный релиз.

Исходники доступны для изучения и разрешённых LICENSE изменений; это не OSI open-source лицензия. Чужие зависимости сохраняют собственные лицензии. Вклад в код должен включать доказанный red → green цикл для изменения поведения и соблюдать границы слоёв.
