# PostField

[Сайт PassField + PostField](https://passfield.ru/postfield/) · [Политика конфиденциальности](https://passfield.ru/postfield/privacy/)

Почтовый индекс по адресу, который уже введён в форму. Первый выпуск — для России; международные страны подключаются после проверки качества.

Издатель: **Kreout**. Публичные исходники и бесплатные официальные сборки для Chrome, Opera, Microsoft Edge и Firefox. Правообладатель сохраняет права на исходный код: см. [LICENSE](LICENSE).

## Принятые решения

- Новая установка: Photon / OpenStreetMap без регистрации и ключа, режим «Авто» и передача адреса включены. Собственного сервера нет.
- В настройках выбирается один источник: Photon, Geoapify с личным ключом или платный DaData Clean с личными токеном и секретом. Ошибка не переключает источник автоматически.
- Переключатели «Все сайты» и «Этот сайт» сохраняют режим. Глобальный «Вручную» останавливает авто везде, а «Авто» учитывает ручные исключения; кнопка заполнения работает в обоих режимах.
- Автовставка требует единственного точного полного адреса дома без конфликтующих индексов. Проверки качества зависят от источника; для Geoapify сохранён [список исправлений](docs/POSTCODE_CORRECTIONS.md). Частичные и неоднозначные ответы требуют выбора. Ручной индекс сохраняется, устаревший ответ отбрасывается.
- Адреса не сохраняются в истории и не отправляются издателю. Получатель — только выбранный сервис; передачу можно отключить. Обновление сохраняет прежний Geoapify, ключ, разрешение передачи и ручные исключения.
- Строгий TypeScript, SOLID и TDD: сначала падающий тест поведения, затем реализация и рефакторинг.
- GitHub Actions собирает четыре пакета; доставка стабильного GitHub Release в магазины предусмотрена через HTTP API и журнал операций. Chrome, Edge и Mozilla имеют контрактные адаптеры; для Opera контракт ещё требуется подтвердить.
- Общий издатель и происхождение сборок; магазины используют собственные подписи и разные ID расширения.

## Установка

| Браузер | Магазин | Публичная версия |
|---|---|---|
| Microsoft Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/lbeapkbfgkokedeepphbphjahopnlaok) | 0.4.1 |
| Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/ekdhmojbkpdgpgeipchaifhoedkgpjgo) | 0.5.0 |
| Firefox, включая Android 142+ | [Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/postfield/) | 0.5.0 |

Карточки проверены 28.10.2026. Firefox предлагает подписанный XPI 0.5.0 и поддерживает постоянную установку на компьютере и Android. Публикация в Opera Add-ons пока не подтверждена; доступны [официальные ZIP-сборки 0.5.0](https://github.com/krotname/PostField/releases/tag/v0.5.0) с ручной установкой. В Chromium распакуйте ZIP своего браузера и загрузите папку в режиме разработчика. Firefox ZIP можно временно загрузить через `about:debugging#/runtime/this-firefox`; для постоянной установки используйте Mozilla Add-ons.

1. Установите расширение из магазина своего браузера.
2. Заполните город, улицу и дом. Для новой установки ключ не нужен: выбран Photon. Другой источник применяется в настройках кнопкой «Сохранить».
3. Проверьте предложенный индекс перед отправкой формы. Для ручного поиска выберите «Вручную» и нажмите «Заполнить сейчас». Если поля не распознаны, используйте ручное назначение.

Локальное избранное сохраняет проверенные индексы; подтверждение подстановки включается отдельно для каждого адреса. Распознавание подписей на 12 языках не расширяет российскую географию поиска. Публичный Photon имеет неполное покрытие домов и не гарантирует доступность. Точное распознавание адреса не доказывает правильность индекса поставщика. Состояние: [checkpoint](docs/release/CHECKPOINT.md), [изменения 0.5.0](docs/releases/0.5.0.md), [живые измерения](docs/evidence/RUSSIA_QUALITY.md).

## Разработка

Требуется Node.js 24+. `npm ci`, затем `npm run check`. Для проверки браузера: `npx --no-install playwright install chromium`, `npm run test:e2e`. CI дополнительно проверяет покрытие, зависимости и Firefox manifest. Выпуск создаёт четыре ZIP, source archive, release manifest и GitHub build attestations из проверенного SHA main.

`npm run benchmark:ru` читает `GEOAPIFY_API_KEY` из окружения; корпус задаётся `CORPUS_PATH`, путь агрегированного отчёта — `REPORT_PATH`. Ключ, ответы с адресами и пользовательские данные в отчёт не попадают. В `tests/fixtures/russia-corpus.json` — 117 разных официальных публичных адресов из 26 регионов; наличие корпуса само по себе не подтверждает качество провайдера.

Исходники доступны для изучения и разрешённых LICENSE изменений; это не OSI open-source лицензия. Чужие зависимости сохраняют собственные лицензии. Вклад в код должен включать доказанный red → green цикл для изменения поведения и соблюдать границы слоёв.
