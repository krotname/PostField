Почтовый индекс по адресу в форме

PostField находит индекс по городу, улице и дому. Расширение для Chrome, Opera, Edge и Firefox; первый этап — Россия.

Предварительные сборки Код и дорожная карта

Автоматический поиск по умолчанию после настройки ключа и согласия, переключатель «Авто / Вручную» для текущего сайта и ручное назначение полей. Единственное точное совпадение города, улицы и дома допускает вставку; неоднозначные ответы предлагаются для выбора. Сохранены исправления известных индексов и ваш ручной ввод. Точность геокодирования не гарантирует правильность индекса. Формы сами не отправляются.

Начало работы

  1. Загрузите ZIP своего браузера из GitHub Release и распакуйте. Это предварительный выпуск; карточки магазинов ещё не опубликованы.
  2. В Chromium откройте управление расширениями, включите режим разработчика и загрузите распакованную папку. В Firefox ZIP допускает только временную загрузку разработчиком; постоянная установка требует подписанного XPI.
  3. Добавьте собственный ключ Geoapify в настройках и разрешите отправку адреса для поиска.
  4. Заполните город, улицу и дом. Для поиска по кнопке выберите «Вручную» в окне PostField на текущем сайте.

Приватность

Издатель не получает ваши адреса и ключи. Geoapify получает город, улицу, дом, страну и при наличии регион после вашего согласия. Квартира, ФИО и URL страницы не отправляются.

Стадия проекта

В исходниках 0.2.0 добавлены авто по умолчанию и распознавание подписей на 12 языках; география остаётся российской. Опубликованный preview 0.1.3 добавил 48 адресных исправлений без собственного сервера. Первый индекс Geoapify расходился с эталоном у 48 из 117 адресов (41,03%); повторных запросов для подсчёта не было. Независимая проверка пока не открыла стабильный выпуск и публикацию в магазинах. Международные страны появятся после отдельной проверки качества.
