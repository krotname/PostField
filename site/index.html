Почтовый индекс по адресу в форме

PostField находит индекс по городу, улице и дому. Расширение для Chrome, Opera, Edge и Firefox; первый этап — Россия.

Предварительные сборки Код и дорожная карта

Разовый поиск, автоматический поиск для выбранного сайта и ручное назначение полей. Для РФ индекс Geoapify нужно проверить перед явным выбором даже при точном совпадении дома. Ваш ручной индекс сохраняется. Формы сами не отправляются.

Начало работы

  1. Загрузите ZIP своего браузера из GitHub Release и распакуйте. Это предварительный выпуск; карточки магазинов ещё не опубликованы.
  2. В Chromium откройте управление расширениями, включите режим разработчика и загрузите распакованную папку. В Firefox ZIP допускает только временную загрузку разработчиком; постоянная установка требует подписанного XPI.
  3. Добавьте собственный ключ Geoapify в настройках и разрешите отправку адреса для поиска.
  4. Откройте значок PostField на странице доставки и выберите разовое заполнение либо автоматический режим для этого сайта.

Приватность

Издатель не получает ваши адреса и ключи. Geoapify получает город, улицу, дом, страну и при наличии регион после вашего согласия. Квартира, ФИО и URL страницы не отправляются.

Стадия проекта

В версии 0.1.1 добавлена защита от неверного автоматического индекса Geoapify. Предварительная 0.1.0 этой защиты не содержит. Проверка на 117 официальных адресах пока не открыла стабильный выпуск и публикацию в магазинах. Международные страны появятся после отдельной проверки качества.
