Почтовый индекс по адресу в форме

PostField находит индекс по городу, улице и дому для адресов России. Установите бесплатное расширение из магазина своего браузера.

Установить для Edge Установить для Chrome Firefox и Android

В Microsoft Edge Add-ons опубликована версия 0.4.1, в Chrome Web Store и Mozilla Add-ons — 0.5.0. Firefox поддерживается на компьютере и Android 142+. Публичные карточки проверены 28 октября 2026 года.

Сборки 0.5.0 на GitHub · Исходный код

Переключатели «Все сайты» и «Этот сайт» задают автоматический или ручной режим. При единственном точном совпадении дома индекс вставляется автоматически, частичные и неоднозначные ответы требуют выбора. Ваш ручной индекс сохраняется; формы сами не отправляются.

Три источника

Photon работает без регистрации и ключа, но имеет неполное покрытие домов и публичный сервер без гарантий доступности. Geoapify использует ваш API-ключ. DaData Clean требует токен и секрет и выполняет платные запросы. Выбор и сравнение источников доступны в настройках, изменение применяется кнопкой «Сохранить». Ошибка не переключает сервис автоматически. Подписи форм распознаются на 12 языках; география поиска остаётся российской.

Начало работы

  1. Откройте магазин своего браузера по ссылке выше и установите PostField. Для Firefox на Android используйте ту же карточку Mozilla Add-ons.
  2. При первой установке Photon и режим «Авто» включены сразу. Заполните город, улицу и дом.
  3. Проверьте предложенный индекс перед отправкой формы. Чтобы запускать поиск кнопкой, выберите «Вручную». Если поля не найдены, используйте ручное назначение.

Для Opera пока доступны официальные ZIP-сборки с ручной установкой. Публикация в Opera Add-ons ещё не подтверждена. Для ручной установки в Chromium распакуйте ZIP своего браузера и загрузите папку через управление расширениями в режиме разработчика; ZIP для Firefox предназначен для временной загрузки разработчиком.

Приватность

Адрес передаётся только выбранному сервису. Издатель его не получает. Передачу можно отключить; ключи и настройки остаются локально. Обновление сохраняет прежний Geoapify, ключ и отключённую передачу.

Приватность · Поддержка

Точное распознавание адреса не доказывает правильность индекса поставщика. Автоматический индекс нужно сверять перед отправкой формы.

Избранные адреса

Сохраните полный адрес и проверенный индекс вручную. PostField использует запись локально до обращения к сервису. Подтверждение при повторной подстановке можно включить отдельно для каждого адреса.

Автоматические ответы сервисов могут быть ошибочными. Проверьте индекс перед отправкой формы.
