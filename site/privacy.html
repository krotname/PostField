Ваш адрес используется только для поиска индекса

Издатель Kreout не получает API-ключи или адреса и не ведёт аналитику. Запрос к Geoapify требует вашего согласия и разового действия либо включения конкретного сайта.

Передаваемые данные

Geoapify получает страну, город, улицу, номер дома, при наличии регион и API-ключ для аутентификации. При сетевом запросе провайдер видит IP-адрес и сетевые сведения. PostField не добавляет ФИО, квартиру, телефон, e-mail, остальные поля или URL страницы. Режим приватного окна по умолчанию не включён.

Локальное хранение

API-ключ хранится в IndexedDB origin расширения; согласие и разрешённые сайты — в локальном storage. Ключ недоступен странице и content script, не передаётся издателю и не синхронизируется браузером. Кэш до пяти минут находится только в памяти; постоянной истории адресов нет. Защита профиля и шифрование диска зависят от ОС; хранилище расширения не является отдельным криптографическим сейфом.

Удаление и управление

Отзовите согласие в настройках, чтобы остановить новые запросы. Уже отправленный запрос нельзя отозвать у провайдера. «Удалить ключ» удаляет локальный ключ и кэш. Удаление расширения удаляет его хранилище. Автоматическое заполнение отключается отдельно для каждого сайта. Формы сами не отправляются.

Поддержка

GitHub Issues публичны: удаляйте личные данные из сообщений и скриншотов. Обращения по почте используются только для поддержки. Контакт издателя: mail@krot.name.
